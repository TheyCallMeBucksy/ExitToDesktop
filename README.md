# Exit to Desktop

A lightweight client-side mod for **7 Days to Die** that adds a native **Exit to Desktop** button to the in-game pause menu.

## Features

- Adds an **Exit to Desktop** button below **Exit Game**
- Uses the game's normal save routine
- Cleanly disconnects from the world
- Exits directly to Windows
- Client-side only
- No configuration
- Lightweight Harmony patch

## Requirements

- Latest stable version of **7 Days to Die**
- Harmony (included with the game)
